# ChatFlow — Real-time Chat App

A full-stack real-time chat application built with the MERN stack (MongoDB, Express, React, Node.js) and Socket.IO for live messaging.

![ChatFlow](https://img.shields.io/badge/MERN-Stack-blue) ![Socket.IO](https://img.shields.io/badge/Socket.IO-Real--time-green) ![JWT](https://img.shields.io/badge/JWT-Auth-orange)

---

## 🚀 Live Features

- 💬 **Real-time messaging** — messages appear instantly using Socket.IO
- 🟢 **Online presence** — see who is online right now
- ✍️ **Typing indicators** — see when someone is typing
- 🔐 **Secure authentication** — JWT stored in httpOnly cookies
- 👤 **User profiles** — update your name, bio and avatar
- 🔍 **User search** — find anyone and start a conversation
- ✅ **Read receipts** — messages marked as read automatically
- ⚡ **Optimistic UI** — your messages show instantly without waiting

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18 + Vite |
| Styling | Tailwind CSS |
| State Management | Zustand |
| Real-time | Socket.IO |
| Backend | Node.js + Express.js |
| Database | MongoDB + Mongoose |
| Authentication | JWT + bcrypt |
| Validation | Zod |
